# LearnHub

LearnHub is an Online E-Learning Management System developed using Django and MySQL.
It provides a platform where students can enroll in courses, learn lessons, submit quizzes and assignments, and receive certificates after completing their courses.

## Features

### Student
- Register and login
- Browse available courses
- Enroll in courses
- Learn course lessons
- Track lesson progress
- Submit quiz answers
- Submit assignments
- View grades
- Receive course certificates
- Manage profile

### Teacher
- Login to teacher dashboard
- View assigned subjects
- View student quiz submissions
- View student assignment submissions
- Grade quizzes and assignments
- View student grades

### Admin
- Manage students
- Manage teachers
- Manage courses
- Manage subjects
- Manage lessons
- Manage quizzes
- Manage assignments
- Manage teacher-subject assignments
- Manage student enrollments
- Manage certificates

## Technologies Used

- Python
- Django
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
